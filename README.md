# Página Web de Marca Personal

Este proyecto contiene una página web estática sencilla para presentar tu marca personal como estudiante de Ingeniería de Sistemas en la Universidad Javeriana.

## Estructura del proyecto

- `index.html` – Página principal.
- `style.css` – Estilos básicos.
- `script.js` – (opcional) JavaScript para interactividad futura.
- `README.md` – Este archivo con instrucciones.

## Instrucciones para publicar en GitHub Pages
1. **Crear un repositorio en GitHub**
   - Ve a https://github.com y crea un nuevo repositorio (por ejemplo `marca-personal`).
2. **Inicializar el repositorio localmente**
   ```bash
   cd "C:/Users/juand/OneDrive/Escritorio/Universidad/5 Quinto semestre/proyecto de innovacion/Marca personal"
   git init
   git add .
   git commit -m "Initial commit - página de marca personal"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/marca-personal.git
   git push -u origin main
   ```
3. **Activar GitHub Pages**
   - En la página del repositorio, ve a *Settings → Pages*.
   - Selecciona la rama `main` y la carpeta `/ (root)`.
   - Guarda. GitHub generará la URL, por ejemplo `https://TU_USUARIO.github.io/marca-personal/`.
4. **Compartir la URL**
   - Envía la URL resultante a tu profesor.

## Personalización
Edita `index.html` y `style.css` para cambiar colores, textos o añadir secciones.
